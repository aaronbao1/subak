# Landing page product captures

Captured on October 25, 2026 from the current Subak UI using the saved `/demo` dataset. The white workspace, purple actions, sidebar, and native dialogs are shown without the old header crop. All videos and matching WebP posters are 1440 × 900 (8:5).

| Asset | Workflow |
| --- | --- |
| `hero` | Company outlook and weekly actual-versus-forecast review |
| `overview` | Company budget, weekly spending, and team allocations |
| `team-breakdown` | Team comparison and an individual spending outlook |
| `requests` | Team requests and a project update with budget context |
| `usage` | Spend/token activity and daily model detail |
| `evidence` | Source search and document detail |
| `reallocate` | Reviewed team redistribution and saved decision |

Each name has a `.webm` recording and `.webp` poster. Replace both together when the app UI changes. Posters are also the fallback for failed video and reduced-motion preferences. Landing videos load on entry, pause offscreen, and have a pause control.

Captures use session-only demo changes. The reallocation moves $12,000 from Payments & Risk to AI Labs without increasing the company budget. The current saved dataset has no dated forecast assumptions, so the landing page shows populated evidence instead of a fabricated Planning scenario.
