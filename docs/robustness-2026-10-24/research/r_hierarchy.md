## Five changes with the largest shared benefit

1. **One semantic path envelope.** Add an immutable, versioned `PathBundle` around the existing joint law: tenant, as-of, target fingerprint, consecutive exact financial dates/timezone, unit/currency/support, scenario ID, method/config/seed, source manifest, and provenance/support status. Preserve global path IDs and weights. A derived view must retain this identity. Reject merges with incompatible metadata or independently generated draws. Keep direct cumulative forecasts in a separate exact-target representation; never fabricate daily samples by spreading a total.

2. **One date-specific accounting projection.** Derive team/day/company totals from physical atoms and an origin-known `Assignment` partition. Weights sum to one including shared/unattributed; overlapping project or membership tags are query views, not an additive company partition. A transfer changes the applicable day, not historical usage or physical identity. If future membership is uncertain, sample membership jointly with activity in each path: `E[M U]` generally differs from `E[M] E[U]`. Unknown hires can be cohort slots; do not invent named identities. Personal reporting remains parked.

3. **One shared stochastic path, with modest identifiable dependence.** Small shared organization/team factors, common release/policy/capability shocks and persistent blocks should be sampled once per path, then reused across people, meters and dates. A reduced empirical challenger can resample entire origin-aligned multientity, multiday residual blocks; shuffling each entity/day separately destroys aggregate dependence. Label block exchangeability/regime assumptions. Bounded or finite-moment structural components belong to the risk worker; correlated heavy-tail stresses are scenarios until real support exists. Do not silently learn a copula from marginal foundation quantiles.

4. **Commercial transformation inside each draw.** Aggregate full billing pools with known prefix state, price complete contract periods once, then allocate resulting signed lines using a versioned policy. Derive monetary quantiles afterward. Across resets, split by actual contract boundaries and rejoin on the same global path ID. Existing nonlinear volume-tier repricing can produce a negative future increment; preserve it instead of clipping. A standalone team bill is a separately labeled counterfactual. An allocation-policy change can move team expense while company expense is unchanged and must not be called usage savings.

5. **Verify identities separately from predictive qualification.** For every draw check atom→team→company, day→requested interval, pooled charge→allocated lines, and immutable path/metadata lineage. Evaluate marginal and aggregate scoring separately, using matched information and the actual decision target. One direct aggregate winner can serve its target without pretending it belongs to the structural joint law. Joint calibration needs real company/calendar support; hierarchy arithmetic alone never establishes it.
